## 1. Round-1 findings

**1. Rubric frozen before grading — RESOLVED.** Steps 4–6 implement grading-first with re-labeling under a frozen v2, `rubric_version` is enforced end-to-end (JA-08 format, JA-09 mixed-version rejection), and rubric changes are recorded in alignment.md. This is the proposed fix.

**2. Threshold/calibration conflation — RESOLVED; the substitute answers the problem, it does not dodge it.** The rejection of prevalence-matching is sound: the matched quantile sets each judge's cut from the very labels the statistic is then evaluated against — an in-sample, per-judge operating point that inflates TPR/TNR and breaks comparability. AUC is exactly the question I asked it to carry ("does this judge rank items like the owner" = P(score|owner-pass > score|owner-fail)) and is immune to the calibration offset that broke the thresholded report; imbalance affects its variance, not its validity, and the stratified bootstrap plus pre-registered "inconclusive" handles small N honestly. Two caveats: the `real`-stratum AUC will be dominated by the ON/OFF contrast (a judge keying on "contexts empty ⇒ low score" scores well there while ranking poorly within ON), so per-arm AUC remains the within-regime view and should be read as such; and the whole design is contingent on new problem N3 below — a stratified bootstrap with 1–2 items in a class produces artifactually narrow AUC/kappa intervals that can fire the pre-registered separation rule.

**3. Easy fail class / empty informative stratum — RESOLVED.** Hard negatives (`negative:owner`, step 7), pre-registered "inconclusive" (A10), and structural quarantine of construction labels (JA-10 strata) were the substance of the fix. The two sub-claims the author rejected are rejected on evidence I accept: Llama's 0.535 on empty contexts refutes my "OFF is near-deterministic fail," and either way the quarantine makes the overstatement path impossible; Yan's perturbation findings make "perturbations will read 0.9+" a prediction, not a given, and it no longer matters because perturbations cannot pool into any real stratum.

**4. No error analysis — RESOLVED.** JA-16 plus pre-registered cause codes plus the step-10 requirement (every disagreement coded, counts per judge per cause) and the conclusion rule keying the GLM question to cause codes on its false fails — exactly the proposed table.

**5. Single labeler — RESOLVED**, with an executability nit (N7). JA-17/18, step 9's delayed blind re-label, and A11's "read kappa against the ceiling, not 1.0" match the fix.

**6. B4 asymmetric and dormant — RESOLVED; the weak floor is adequate.** An always-fail judge scores below any floor > 0 on every probe, so "no pass probe ≥ pass_floor" rejects it, and JA-06's 0.0-stub test pins this. A correct strict judge needs one probe to clear the floor; with 21/23 digit cases fully grounded and the clean fixture at 0.8, a judge that cannot clear a single plausible pass probe is degenerate for screening purposes — and sb-028/sb-035 are exactly the evidence that a *strict* rule would wrongly reject correct-harsh behavior on genuinely ungrounded expected answers. Dormancy is now honestly documented (JA-07). The substitute answers the problem.

**7. `overall` stratum — RESOLVED.** Strata are per-arm plus `real`; pooling is prohibited and the Task 3 acceptance tests the prohibition.

**8. judge_runs ≥ 3 — RESOLVED; the substitute is better than my fix.** Code verification (temperature 0.0 defaulted, `build_judge` doesn't override) makes `judge_runs > 1` literal copies — averaging copies is dead cost — while the provider-determinism question was genuinely unmeasured and step 8 measures it on exactly the surface that matters, with a pre-registered escalation (A12). Contingent on N2 and N4 below: the probe has no defined output to read, and it currently sits between labeling and the blind re-label.

**9. Generator unrecorded — RESOLVED.** Router verified in code; step 2 pins `AXON_COMPLETION_MODEL`, records it, flags same-family judges.

**10. Scoring-input integrity — PARTIALLY RESOLVED.** The perturbation-item field pinning (the concrete half) is done in JA-14; the checksum rejection on YAGNI grounds is defensible for a single-owner pilot with no adversarial pressure, and JA-17's exact-match join incidentally cross-checks answer/contexts identity on the 20 re-labeled items. I accept the residual.

Deferral-audit items: test-only declaration and construction-labels-out-of-the-owner's-file both adopted (step 1, JA-10 echo, two-file export).

## 2. New problems introduced by the revision

**N1. BLOCKING — Step 4's spread selection reads data no defined artifact contains.** "The 10 with the largest cross-judge faithfulness spread (selected by the agent from the run JSON)": the spec's own verified bullets establish that `panel_to_dict`'s `per_case` is `{case_id, total_tokens, latency_ms}` and Task 1 adds only `responses` — per-case judge scores exist nowhere in the run JSON this feature defines, and the align loader requires filled verdicts, so the agent can't score the todo file either. Smallest fix: change step 4 to 15 seeded-random items; if the spread focus is kept, specify the agent computes it out-of-band (a throwaway scoring script, METRON-style) with scores never shown to the owner.

**N2. BLOCKING — Step 8 is not executable from the defined CLI surface.** `gnomon align` prints JA-10 aggregates and the JA-16 disagreement list only; a run with zero disagreements exposes no scores, and identical aggregates do not imply identical per-item scores (rounding, ties, compensating differences), so "record whether scores are identical" has nothing to read. Smallest fix: Task 4 gains `--dump-scores PATH` (per-item per-judge scores, covered by NFR-03 byte-identity); simpler still, run the full step-10 command twice and byte-compare the two dumps — that upgrades the probe from 10 items to every item at trivial cost and deletes the 10-item-file machinery.

**N3. BLOCKING — Stratified bootstrap with 1–2 items in a class yields artifactually narrow intervals that can fire the conclusion rule.** "Class counts preserved" means a minority class of size 1 contributes zero resampling variance, so non-overlap can be an artifact of the scheme, and step 10's mechanical rule ("intervals do not overlap") would mint a false "judge X is more aligned than judge Y." The likely strata are exactly the ones A10 predicts will be small (ON-arm fails, OFF-arm passes). Smallest fix: one JA-11 clause — below ~5 items in a class, report point estimates and Wilson only, bootstrap interval `null` with reason; the conclusion rule cannot fire on a null interval. (Wilson at n=1–4 is already honest; only the bootstrap needs the guard.)

**N4. ADVISORY — Step 8 sits between labeling and the step-9 blind re-label.** Whoever runs it sees judge scores before the owner re-labels, contaminating the self-agreement ceiling. Smallest fix: reorder steps 8 and 9, or state the agent runs step 8 and the owner sees only identical/not.

**N5. ADVISORY — `negative:owner` item fields are unpinned.** The fail-by-construction guarantee is relative to specific contexts, but nothing says negatives carry the case's `expected_contexts` (JA-14 pins this for perturbations only), nor their `rubric_version` value (required non-empty by JA-08). Smallest fix: one sentence in step 7 mirroring JA-14's perturbation pinning.

**N6. ADVISORY — The conclusion rule doesn't name its statistic.** "Intervals do not overlap in the same stratum" leaves ~5 statistics × ~5 strata selectable post hoc — a multiplicity loophole inside a pre-registered rule. Smallest fix: step 1 pre-registers the primary statistic per claim type (e.g., "more aligned" ⇒ AUC on `real`; gate behavior ⇒ TPR/TNR on ON; within-regime ranking ⇒ per-arm AUC).

**N7. ADVISORY — Step 9's blind re-label file has no defined production path, and JA-12's seed source is unnamed.** Copying the filled v2 file and nulling verdict/critique works and preserves JA-17's exact-match join, but a hand-retyped file will fail-closed on answer/contexts mismatches; one sentence fixes it. Also state which config field supplies the seed (the ADR-0008 one), since JA-12 defines no `--seed`.
